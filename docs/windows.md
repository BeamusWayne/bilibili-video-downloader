# Windows 使用说明

[返回首页](../README.md)

## 启动

从 [Releases](https://github.com/BeamusWayne/bilibili-video-downloader/releases) 下载安装包，或解压便携 ZIP 后运行 `BilibiliVideoDownloader.exe`。保留同目录的 `tools` 和 `licenses`。需要 Windows 10 / 11 x64 和 WebView2。

关闭窗口默认进入托盘，彻底退出请使用托盘菜单，或在设置中关闭托盘运行。

## 下载流程

1. 在「账号」扫码或导入 Cookie。
2. 在「新建下载」粘贴链接，每行一条，也可导入 TXT。切换页面会保留草稿。
3. 点击「解析链接」，弹窗展示解析进度、内容与失败项。
4. 勾选分 P，展开输出选项，调整格式、画质和目录。
5. 点击「开始下载」，任务入队，界面自动切换到下载队列。

关闭正在解析的弹窗会停止解析。再次解析会刷新本轮内容，不混入上一次结果。

## 批量任务

队列按状态筛选、按标题和 UP 主搜索。批量按钮作用于当前列表的选中任务；未勾选时作用于当前列表中符合条件的任务。暂停只影响排队和进行中的任务，继续只影响暂停任务，重试只影响出错任务。

建议先保持默认并发：3 个下载任务、每文件 4 连接、总计 12 连接、1 个转码任务。站点限流时，提高连接数通常无法加速。

右侧更多按钮打开详情，查看错误、附件警告、缓存和画面处理。清理缓存会失去已下载的源文件，再次导出可能需要重下；移除任务不会删除已导出文件。

## 输出

视频选 MP4 / MKV；常用音频选 MP3 / M4A；FLAC / WAV 无法还原原本有损音轨的信息。视频默认尽量直接封装，若播放器不支持源编码，可启用兼容模式导出 H.264 / AAC。

模板支持 `{UP主}`、`{标题}`、`{分P标题}`、`{P序号}`、`{BV号}`。非法字符会替换，长名称会截短，任务短 ID 防止同名覆盖。

## 头像和数据

头像和资料缓存到本机，重启先读缓存，再验证登录。网络不可用时显示「登录状态待验证」。退出登录清除凭据和当前账号资料、头像缓存。

- 凭据：Windows 凭据管理器。
- 数据：`%APPDATA%/com.local.bilibili-video-downloader/`。
- `tasks.db` 保存队列和设置；`cache` 保存媒体与断点；`previews` 保存预览；`profile` 保存资料和头像。
- 解析时生成短期 Cookie 文件，正常结束删除，启动清理残留。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 412 / 429 | 确认登录，等待冷却再重试，保持适度并发 |
| 恢复少了一点进度 | 当前未确认分片会重下；源变化或无可靠验证器时安全重下 |
| 下载后仍在处理 | 正在封装、转码或检查输出，转码有独立并发 |
| 重启重新转码 | 源缓存仍可复用，转码从头完成 |
| 附件未保存 | 查看详情警告，并非所有视频都有字幕 |
| 磁盘占用较大 | 分片、合并缓存、成片同时存在，不再需要恢复时清理缓存 |
| 区域处理不理想 | 先预览，按需保留原片；滤镜不能恢复所有被覆盖的细节 |
